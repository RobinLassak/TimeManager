# Worklog — 2026-08-19

Kód psal uživatel. AI sloužila jako rádce. AI psala jen tuto dokumentaci.

## Cíl dne

Napsat controller vrstvu pro Customer a napojit API endpointy nad `CustomerService`.

## Co se udělalo

### Analýza projektu
- Projita architektura: Entity → DTO → Service → Controller
- Service vrstva (Customer / Project / Work) už byla hotová z předchozích dní
- Controller a URL routing chyběly

### První verze — Django View
- Vytvořena složka `app/controllers/` včetně `__init__.py`
- Napsán `app/controllers/customer_controller.py` (kód psal uživatel)
- Nejdřív třída `CustomerController(View)` s metodami `get` / `post` / `put` / `delete`
- `JsonResponse` + `asdict` + `DjangoJSONEncoder` (datetime v JSON)
- `id` u update/delete z URL, ne z těla
- 404 když service vrátí `None` / `False`; create → 201; delete → 204
- Dočasně `app/urls.py` + `include` v `config/urls.py`
- Ověřeno v prohlížeči: `GET /api/customers/` vrací `[]`

### Přechod na Django Ninja (Swagger)
- Zvolena cesta jako v Nest / .NET — dokumentace přímo v projektu
- Nainstalováno `django-ninja` (uživatel)
- Controller přepsán z `View` na `Router` + funkce (kód psal uživatel)
- HTTP schémata `CustomerIn` / `CustomerOut` (`Schema`); do service pořád jde `CustomerDTO`
- Helper `_to_dto` (Schema → DTO)
- CRUD routy: `GET /`, `GET /{id}`, `POST /`, `PUT /{id}`, `DELETE /{id}`
- 404 přes `HttpError`; create `return 201, ...`; delete `return 204, None`

### Napojení API
- Napsán `app/api.py` — `NinjaAPI` + `add_router("/customers", ...)`
- `config/urls.py` přepnut na `path("api/", api.urls)`
- Smazán `app/urls.py` (starý View routing)

### Kontrola / opravy při psaní
- `Router` musí být v importech; `NinjaAPI` patří do `api.py`, ne do controlleru
- `asdict` umí jeden DTO, ne seznam — list přes comprehension
- `response={201: CustomerOut}` vyžaduje `return 201, tělo`
- `CustomerOut.created_at` / `updated_at` jako `datetime`, ne `str`

### Ověření ve Swagger UI
- `http://127.0.0.1:8000/api/docs` běží
- `POST` vytvořil zákazníka, `GET` ho vrátil, `DELETE` ho smazal, seznam znovu `[]`

## Stav na konci dne

- Customer API kompletní (CRUD) přes Django Ninja
- Swagger dostupný na `/api/docs`
- Tok: request → Router → Schema → DTO → Service → Entity → DB
