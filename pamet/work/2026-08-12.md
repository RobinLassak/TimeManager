Napsat první service vrstvu — `CustomerService` s CRUD a mapováním DTO ↔ Entity.

## Co se udělalo

### Service vrstva
- Vytvořena složka `app/services/` včetně `__init__.py`
- Napsán `app/services/customer_service.py` (kód psal uživatel)

### CustomerService — CRUD
- `get_all_customers` — list všech zákazníků jako DTO
- `get_customer_by_id` — detail; při neexistujícím ID `None` (`DoesNotExist`)
- `create_customer` — DTO → entita → `save` → DTO
- `update_customer` — kontrola `id` + existence, pak `_to_entity` + `save` + `_to_dto`
- `delete_customer` — smazání podle ID, návrat `bool`

### Mapování
- `_to_dto` — Entity → DTO (včetně `id`, `created_at`, `updated_at`)
- `_to_entity` — DTO → Entity (business pole + `id`; timestampy se z DTO nemapují — řeší `auto_now` / `auto_now_add`)

### Domluvené principy
- Service je třída, konstruktor zatím není potřeba
- Ven ze service jde vždy DTO, ne Django entita
- Update přes helpery, ne ruční výpis všech polí
