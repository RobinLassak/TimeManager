Zavést mezivrstvu DTO a připravit se na service vrstvu s CRUD.

## Co se udělalo

### Architektura / naming
- Vyjasněno pojmenování vrstev:
  - **Entity** = Django model, ukládá se do DB (`app/entities/`)
  - **DTO** = mezistupeň mezi controllerem a entitou (`app/dto/`)
  - **Service** = CRUD + převody DTO ↔ Entity (ještě není)
- Tok: Controller → DTO → Service → Entity → DB (a zpět)

### DTO vrstva
- Vytvořena složka `app/dto/` včetně `__init__.py`
- `CustomerDTO` — pole sjednocena s entitou `Customer`, `id` / timestampy volitelné
- `ProjectDTO` — FK jako `customer_id` (ne vnořený customer), data jako `date`
- `WorkDTO` — FK jako `project_id`, stejný vzor jako Project
- Domluvena pravidla dataclass: povinná pole bez defaultu nahoře, volitelná dole
- Vyjasněno, že `Field(...)` patří k Pydanticu, ne k `@dataclass`
- Vyjasněno, k čemu je (a není nutný) `to_dict()` / `asdict`

### Co se neřešilo
- Service vrstva zatím nevznikla
- Controllery zatím ne
- Validace přes Pydantic zatím ne
